# Asset permission ledger

All committed cases are original symbolic TEST_ONLY fixtures containing invented
store/product names and no image or personal data. They are software test data,
not a licensed OCR image corpus. Their `licenseReference` and `permissionReference`
are MISSING to prevent them being counted toward production evaluation.

Real asset intake requires asset/source/document IDs, permission or license record,
source provenance, retention/access policy, redaction review, original bytes hash
and preprocessing lineage. Record license scope and allowed provider processing
before moving an asset into a candidate pilot. Keep private/copyright bytes in the
approved evidence store; public manifests carry only reviewed metadata and hashes.
No real assets have been ingested in this checkpoint.

# Synthetic scan image tests

Classification: TEST_ONLY. These are generated illustrations and documents,
not a licensed real-image goldset or a provider quality certificate.
The original `qa/ocr/synthetic` historical baseline stays unchanged.

The deterministic seed 20261012 creates 24 source documents: six Vietnamese
receipts, six Japanese receipts, six product labels (three per locale), and six
refrigerator illustrations. Each has clean, blur, tilt, low_light and missing_field
variants: 120 valid PNG/JPEG files plus one deliberately damaged JPEG.
Twenty-four source documents are not 120 independent real samples. Templates
and related text repeat; calibration/heldout only exercise split isolation.

Source rows and annotations are saved before rendering; missing-field labels
reflect what is actually drawn. Source positions preserve duplicate purchase
occurrences. Prices explicitly use VND or JPY with zero decimal minor units.
Refrigerator quantities, mass and covered contents remain UNKNOWN. Canonical
IDs, taxes, purchase dates and unstated expiry facts are never inferred.
Tilted visual regions are transformed into final image coordinates.

## Reproduce locally

From repository root, with Node >=22.13 and frozen dependencies:

```sh
node scripts/generate-synthetic-scan.mjs
node scripts/test-synthetic-scan-browser.mjs
swift scripts/ocr-synthetic-scan-apple-vision.swift
node scripts/score-synthetic-scan.mjs
swift scripts/ocr-synthetic-scan-apple-vision.swift .artifacts/scan-synthetic-v3/browser-images/prepared.json .artifacts/scan-synthetic-v3/browser-images/apple-vision.raw.json
node scripts/score-synthetic-scan.mjs .artifacts/scan-synthetic-v3/browser-images/prepared.json .artifacts/scan-synthetic-v3/browser-images/apple-vision.raw.json .artifacts/scan-synthetic-v3/browser-images/scores.json
```

Generated images, source/annotation manifests and raw results live only in ignored
`.artifacts/scan-synthetic-v3`. Use the generator's first positional argument to
choose another output directory. Never upload user photographs into this corpus.
The generator requires no credentials or network. The bundled 22KB Japanese font
subset is SIL OFL 1.1, pinned by source/subset SHA256 with its license; Vietnamese
rendering reuses the existing repository's Nunito test font/OFL. Font subsetting
was a one-time preparation step, not a new runtime or package dependency.
Image bytes are reproducible on the same pinned renderer; cross-OS renderer changes
require a new measurement, not an assumed identical hash.

## What the tests measure

Apple Vision on macOS reads actual image pixels, with language correction disabled.
The runner never reads annotations; input image hashes and manifest hash bind its
raw observations. The scorer uses spatial template regions and reports exact text,
whitespace-insensitive text and character error separately by task/locale/quality.
Each OCR fragment supports one field at most. This is text extraction, not semantic
quantity/money parsing, canonical matching, inventory acceptance or Takosan Qwen
accuracy. Refrigerator text accuracy is null: no object recognition is measured.
All raw failures remain recorded, including the damaged JPEG.

The Chromium harness executes the real `readPrivateImage` module with native file
input, createImageBitmap, canvas JPEG and FileReader. It checks all 120 valid images
plus an oversized receipt against the 2000px cap, decodes output and records exact
hashes/MIME/sizes. Actual browser output images feed a second Apple Vision run.
Cancellation, household change and session reset fence stale callbacks. A damaged
image falls back to original bytes; this helper is preprocessing, not image-content
validation. All browser requests remain on its ephemeral loopback server.

Adapter tests send real generated bytes through existing Qwen request serialization
with fetch intercepted. Responses are deliberately artificial; these assertions
measure MIME/bytes/schema/rejection only. V1 rejects unknown quantity; V3 preserves
UNKNOWN. Neither set can certify model performance or substitute for independent
real labels, provider privacy/pricing/retention evidence or a capped paid benchmark.

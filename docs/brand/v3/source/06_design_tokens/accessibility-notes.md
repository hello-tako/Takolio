# Takosan - Accessibility and color use

Target: WCAG 2.2 AA where applicable. Test in actual components and themes.

Measured contrast ratios (normal text needs 4.5:1; large text 3:1):

- Deep Ink `#202C28` on Cream `#FFF8F3`: approximately **13.75:1** (AA/AAA).
- Leaf Green `#2E7D5B` on White: approximately **5.00:1** (AA normal text).
- Grey `#6F746E` on Cream: approximately **4.54:1** (AA, limited margin).
- Coral `#FF7B6B` on White: approximately **2.53:1** (**FAIL** for text); reserve coral for decorative areas/mascot, or pair with dark text.

Use dark ink text for yellow, mint, or coral surfaces. White text on Leaf Green for primary actions. Preserve visible keyboard focus, minimum 44px targets and non-color error states. Icon-only buttons require accessible labels. Mascot is decorative unless the illustration meaningfully conveys new information.

# Culinary research protocol

Research is a comparison activity:

1. read V1 and V2;
2. compare every identity, ingredient, quantity, step, timing, and metadata field;
3. identify safety, process, and cultural correctness risks;
4. retrieve source evidence without copying source prose;
5. record conflicts and unresolved claims;
6. create a candidate diff;
7. run deterministic checks;
8. route the candidate to human review.

The first pilot contains 20 IDs from Vietnamese, global, imported, steamed,
fried, vegetarian, noodle, soup, and breakfast groups. A pilot item remains
review-pending unless every changed fact has source evidence and an independent
reviewer.

Observed pilot risks include step ingredients absent from lists, repeated salt
use against one declared total, sugar used across marinade and caramel phases,
and derived pork/crackling/lard quantities that cannot be added as direct
intake. These are review findings, not automatic corrections.

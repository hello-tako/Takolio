# External acceptance checklist

All rows below are PENDING_EXTERNAL_EVIDENCE. They do not block independent
local implementation or synthetic/mock verification. Budget currently USD 0;
real OTP, paid AI and production changes require separate user approval.

| Region | Required evidence and owner action |
| --- | --- |
| Auth/email | Controlled recipient permission, actual accepted/delivered/bounced receipts, registration/login/reset/Google/session and supported Safari/Turnstile challenge journeys. No OTP/address in general evidence. |
| Billing | PayOS sandbox order/status/uncertainty behavior, original-offer replay and late-paid operator resolution; approved financial/privacy retention and refund policy. No live transfers in this packet. |
| AI/OCR | 240 permitted real assets with source groups, hashes, consent/retention and independent labels. Exact model/API/capability/privacy/input-token/output-cap/current-price evidence. Explicit paid ceiling before paired calls/repair/retry/shadow. |
| Ingredient V2 | Human 40 concept/60 transformation/20 URL pilot, then full source/license/conversion/nutrition review. Resolve all four derived release blockers before migration/cutover. Synthetic decisions never count toward human denominators. |
| Planner/stock/shopping | Hosted multi-isolate/load and physical device journeys; data V2 consumer acceptance against a certified release. Existing authority offline invariants remain independently testable. |
| API | Exact hosted schema/response/consumer verification and compatible staged rollout for new billing schema. Offline contracts are source-bound only. |
| Operations | Approved numerical targets, real collector/access/retention, alert destination and delivery, seven-day adequate-sample SLO, hosted controlled load/chaos, separate recovery rehearsal. |
| Security/platform | Independent workflow promotion review, Linux/hosted execution and supported native/browser floor; separately approved compatibility-date change. No branch protection modification. |
| Product VNext | Product/entitlement/data owners approve family roles, notification consent/timezone, purchase conversion evidence, catalog admin, trial policy and analytics retention before activation. |
